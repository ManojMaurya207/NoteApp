# 📝 Simple Notes – iOS Todo App

A **simple and lightweight iOS notes app** that helps users create todo lists and keep track of tasks in hand.

This is my **first-ever iOS application**, built as a learning project to understand iOS fundamentals such as UI development, state management, and basic data handling.

---

## ✨ Features

- ➕ Create notes and todo items  
- ✅ Mark tasks as completed  
- 🗑️ Delete tasks  
- 📋 Simple and clean UI  
- ⚡ Fast and easy to use  

---

## 🎯 Purpose of This Project

- Learn iOS app development basics  
- Understand Swift syntax and iOS app lifecycle  
- Practice UI building and user interactions  
- Build a real, usable app instead of just demos  

---

## 🛠️ Tech Stack

- **Swift**
- **SwiftUI** 
- **Xcode**
- iOS SDK

---

## 📱 Screens & Functionality

- Add tasks you need to complete  
- View all tasks in one place  
- Keep track of work without distractions
